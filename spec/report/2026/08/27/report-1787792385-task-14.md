## Report on task 14: Capsolver adapter + facade

### Spec/ADR amendments

- [acted] **Public `task_id` widened `int` → `int | str`** (TaskRef,
  TaskResult, TaskStatusResult, SubmitAccepted, TaskEvent, engine `_event`,
  `BaseAdapter.build_task_status`): Capsolver addresses tasks by UUID
  string, which the int-only contract could not represent. Owner-approved
  (decision 1). architecture.md §4 tables updated.
- [acted] **GeeTest v4 now covered on all four providers**: current
  Capsolver docs document `captchaId`/`riskType` on `GeeTestTask[ProxyLess]`;
  the ADR-0076 exclusion ("official SDK ships GeeTest v3 only") was
  SDK-stale (2024 clone vs 2026 docs). ADR-0076 + architecture §2 amended.
- [acted] **Turnstile task type corrected**: it is
  `AntiTurnstileTaskProxyLess` (proxyless-only; userAgent ignored), not
  `AntiCloudflareTask` (which is the Cloudflare-challenge task) nor
  "proxy opt". ADR-0076 + architecture §2 amended. `chl_page_data` is not
  supported (challenge rejects it).
- [open] hCaptcha / FunCaptcha have **no Capsolver docs pages** in the
  current nav (SDK-only type strings); mapping follows the SDK +
  spec (`rqdata→rqdata`, `public_key→websitePublicKey`). Revisit if
  docs pages appear.
- [open] reCAPTCHA v3 enterprise: Capsolver has no v3-enterprise task type
  — `CapSolverRecaptchaV3Challenge` rejects `is_enterprise`. If Capsolver
  later adds `ReCaptchaV3EnterpriseTask`, revisit.
- [open] Capsolver referral is **inert**: no affiliate-id field exists in
  the API; `referral=` is accepted for parity (ADR-0072) but no `softId` is
  emitted. ADR-0072's "CapMonster/Capsolver equivalents" needs a note that
  Capsolver has none.
- [open] Image (ImageToText) is proxyless and **instant** (createTask
  returns `ready`+solution) — corrected "proxy opt" and relies on the
  ADR-0075 instant fast path.

### Future-task notes

- Task 15-17 (test scaffold, engine injectable-clock tests, golden
  payloads): golden fixtures must derive from vendor sources (deferred item
  22). Capsolver is the hardest to fixture (dict-driven, string taskIds,
  instant path) — capture live examples.
- The four adapters now share near-identical helpers; consider a shared
  JSON-family base before any new provider work.
- Capsolver solution `type` field (e.g. `"turnstile"`) disambiguates bare
  token solutions — the first provider where shape-keyed parsing can be
  precise; v3 still classifies as RecaptchaV2 (gRecaptchaResponse) per the
  known limitation.

### Tooling/process

- Facade generation by sibling-transform is now routine but fragile: the
  async-pass regex bug (task 13) was avoided by distinct sync/async
  matchers; this task additionally hit (a) class-name drift (`CapSolver*`
  vs spec's `Capsolver*`) and (b) facade aux-op signatures needing
  `int | str`. Both caught by mypy + the spec cross-check.
- Capsolver docs are the authoritative wire source and ahead of the 2024
  SDK clone (GeeTest v4, Turnstile task type) — for this provider the docs
  beat the vendored SDK; the fidelity method (deferred item 22) should
  version-check SDK clones against docs before trusting either.
