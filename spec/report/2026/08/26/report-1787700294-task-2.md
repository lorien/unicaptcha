## Report on task 2: Core models and public types

### Spec/ADR amendments

- [open] ADR-0067: re-scope TaskTicket non-constructibility — expressed as
  documentation ("created by submit(); do not construct"), not a runtime
  guard (Python cannot prevent construction of a concrete public
  dataclass; a sentinel kwarg is a footgun marker for no safety).
- [open] ADR-0014: pin the strict `SecretStr` equality semantics —
  comparing to anything other than `SecretStr` raises `TypeError`
  (`None` compares `False`); note the consequence that probing a
  `SecretStr`-keyed dict with a plain `str` raises `TypeError` (hash
  collision), not a silent `KeyError`.
- [open] architecture.md: the `Proxy` field sketch shows `kind` first, but
  dataclass default-ordering requires required `host`/`port` first.
  Illustrative only; no ADR change needed, but a reader may blink.
- [open] architecture.md: the `_internal/` listing ("engine, http layer,
  clock, scrubbing") could mention config resolution (the field-wise merge
  lives in `_internal/config.py`).
