## Report on task 9: TaskEngine

### Spec/ADR amendments

- [open] ADR-0075/0067 amendment: `TaskTicket` gained a `time:
  TimeConfig | None` field (resolved solve-timeline carried from submit).
  The ADRs' ticket sketches show only task_ref/submitted_at/
  instant_answer; the fresh-ticket poll rule (ADR-0030) and wait's
  default budget (ADR-0067) are unimplementable without kind timing at
  wait time, and the ticket is the only pure-data vehicle (an engine-side
  cache is the ADR-0060 anti-pattern). Pin the field in ADR-0075.
- [open] Task 7's SDK contract gained concrete `build_task_status` /
  `build_balance` (JSON-family defaults) per the owner decision — worth
  adding to ADR-0053's member table so third-party authors see the
  override points for divergent protocols.
- [open] `wait_ref`'s default budget/cadence when `timeout=None` uses the
  generic fallback (120 s / 5 s interval) — no per-kind timing exists for
  a bare TaskRef. ADR-0067 doesn't state this; worth a one-line pin.
